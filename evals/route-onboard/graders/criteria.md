# Criteria: route-onboard

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Starts the onboarding interview rather than drafting a note
- [ ] Asks about audience, with internal as the default
- [ ] Asks for the release definition (fixVersion released, deploy tag, or Done in window)
- [ ] Asks for the time window with a timezone and a cadence
- [ ] Says each source will be tested with a live read before it is saved
- [ ] Says setup ends with a dry run sent to the owner only
